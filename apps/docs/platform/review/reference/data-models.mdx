The Review module owns one data model, `Review`. It’s defined in `packages/core/src/modules/review/models/review.ts` and stored in the `review` table. Resolve the module with `MercurModules.REVIEW`.

## Review

A customer’s rating of one product or one seller. Table `review`, id prefix `rev`.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `text` | Primary key with the prefix `rev`, such as `rev_01JD8Q1234567` |
| `display_id` | `autoincrement` | Serial number for display, stored as a Postgres `serial` |
| `reference` | `enum` | The target type: `product` or `seller`. Required |
| `rating` | `number` | The score, stored as an `integer`. Required, no range constraint in the model |
| `customer_note` | `text` | The customer’s text. Nullable, searchable |
| `seller_note` | `text` | The store’s answer. Nullable, searchable |
| `status` | `enum` | `pending`, `published`, or `rejected`. Default `pending` |
| `created_at` | `timestamptz` | Set on creation |
| `updated_at` | `timestamptz` | Set on every change |
| `deleted_at` | `timestamptz` | Nullable. Set by a soft delete |

The model has no column for its target, order, or customer. Those live in [module links](/platform/review/reference/links), and `reference` tells you whether to follow `product` or `seller`.

### Indexes

Two indexes speed up the lists the APIs run:

| Index | Columns | Condition |
| --- | --- | --- |
| `IDX_review_deleted_at` | `deleted_at` | `deleted_at IS NULL` |
| `IDX_review_reference_status_created_at` | `reference`, `status`, `created_at` | `deleted_at IS NULL` |

### Relations

The model defines no relations of its own. Through links, a review exposes these `query.graph` fields:

| Field | Target | Set when |
| --- | --- | --- |
| `product` | Product | `reference` is `product` |
| `seller` | Seller | `reference` is `seller` |
| `order` | Order | Always |
| `customer` | Customer | Always |

### Types

`@mercurjs/types` exports `ReviewDTO`, `ReviewReference` (`"product" | "seller"`), and `ReviewStatus` (`"pending" | "published" | "rejected"`) for this model.

Use Mercur to decide who can sell on your marketplace and what each person on a store’s team can do.

A store is the account a seller trades under. Offers, orders, payouts, and storefront pages all link back to it, and its team works only inside it. The Seller module holds the store record, its business details, its members and invites, and its status. Other marketplace modules attach to a store through module links, never through direct references.

<Note>
  The Admin and Vendor panels call it a store. The code calls the same record a `Seller` (id prefix `sel`), and you resolve its module with `MercurModules.SELLER` from `@mercurjs/types`.
</Note>

## Key features

The Seller module covers the full life of a store account:

- **Many-to-many teams**: a member can belong to several stores and picks the active one per request
- **Owner protection**: the store’s owner membership can’t be removed or have its role changed
- **Seller roles**: each membership stores one of five `SellerRole` values, from administration to support
- **Token-based invites**: signed invite tokens that expire after 7 days by default
- **Governed lifecycle**: four statuses, each transition run by its own workflow with a hook and an event
- **Scheduled closures**: a `closed_from` and `closed_to` window that hides a store from the Store API without changing its status
- **Premium flag**: an `is_premium` boolean the operator sets for featured placement
- **Region assignment**: every store links to one or more regions, starting with the default region

## How it works

A store moves from creation to trading in a fixed order:

1. A seller registers, or your code runs `createSellersWorkflow`, and the store starts in `pending_approval`
2. The workflow links the store to the default region and to any `region_ids` you pass
3. The first member joins as owner, either at registration or by accepting the invite the workflow sends
4. The operator runs `approveSellerWorkflow`, and the store becomes `open`
5. The Store API lists the store and its offers while it’s `open` and outside a closure window

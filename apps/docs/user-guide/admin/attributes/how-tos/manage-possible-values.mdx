---
title: "Manage an Attribute's Possible Values"
description: "Add or reorder the values sellers can choose from for a select attribute."
---

For select attributes (Single Select and Multi Select), the possible values are the choices sellers pick from when they fill in a product. You can add new values or change the order they appear in at any time. This guide manages the possible values of an existing attribute from the Admin Panel.

<Steps>
  <Step title="Open the Attributes settings">
    Go to **Settings**, then **Attributes** in the sidebar. The page lists every product attribute in your catalog, along with its handle and type.
    <Frame>
      <img src="/images/user-guide/admin/manage-possible-values/step-1.png" alt="Open the Attributes settings" />
    </Frame>
  </Step>
  <Step title="Open a select attribute">
    Choose a **Single Select** or **Multi Select** attribute from the list, since only those types have possible values. Selecting a row opens the attribute's detail page.
  </Step>
  <Step title="Review the possible values">
    The **Possible values** section lists each value and its rank. From here you can **Create** a new value, **Edit ranking** to change the order the values appear in, or use a value's row menu to edit or delete it.
    <Frame>
      <img src="/images/user-guide/admin/manage-possible-values/step-3.png" alt="Review the possible values" />
    </Frame>
  </Step>
  <Step title="Open the create-values form">
    Select **Create** in the **Possible values** section. The form opens on the **Values** step, where you add one or more new values.
  </Step>
  <Step title="Add one or more values">
    Enter a value, and use **Add value** to add more rows. Drag the handle to reorder rows before continuing.
    <Frame>
      <img src="/images/user-guide/admin/manage-possible-values/step-5.png" alt="Add one or more values" />
    </Frame>
  </Step>
  <Step title="Organize the ranking and save">
    Select **Continue** to reach **Organize Ranking**, drag the values into the order sellers should see them, then select **Save**. To change a single existing value instead, use its row menu and choose **Edit**; to reorder without adding values, use **Edit ranking**.
  </Step>
</Steps>

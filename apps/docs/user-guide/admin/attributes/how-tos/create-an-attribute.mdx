---
title: "Create a Product Attribute"
description: "Add a new attribute and choose how it stores its value."
---

An attribute is a reusable property that sellers apply to their products, such as material or size. Creating one is a two-step form: the Details step names the attribute and sets how it behaves, and the Type step chooses how its value is stored. This guide creates an attribute from the Admin Panel.

<Steps>
  <Step title="Open the attributes settings">
    Go to **Settings**, then **Attributes** in the sidebar. The page lists every attribute sellers can apply to their products. Select **Create** to start a new one.
    <Frame>
      <img src="/images/user-guide/admin/create-an-attribute/step-1.png" alt="Open the attributes settings" />
    </Frame>
  </Step>
  <Step title="Open the create form">
    The attribute form opens with two steps: **Details** names the attribute and sets how it behaves, and **Type** chooses how its value is stored.
  </Step>
  <Step title="Enter the details">
    In **Details**, enter a **Title** for the attribute, for example Material. Optionally add a **Handle** (Mercur generates one from the title if left blank) and a **Description**. Use the switches to mark the attribute as **Required attribute**, **Filterable attribute** on the storefront, or **Global attribute** across all products. When **Global attribute** is off, choose the **Categories** it applies to.
    <Frame>
      <img src="/images/user-guide/admin/create-an-attribute/step-3.png" alt="Enter the details" />
    </Frame>
  </Step>
  <Step title="Continue to the type">
    Select **Continue** to move to the **Type** step.
  </Step>
  <Step title="Choose the type">
    Open **Type** and pick how the value is stored: **Single Select** (one value from a list), **Multi Select** (one or more values), **Unit** (a number with a unit of measurement), **Toggle** (on or off), or **Text Area** (free text). For a select type, add the possible values sellers can choose from. For **Multi Select**, you can turn on **Use for variants** so the attribute splits a product into separately purchasable variants.
    <Frame>
      <img src="/images/user-guide/admin/create-an-attribute/step-5.png" alt="Choose the type" />
    </Frame>
  </Step>
  <Step title="Create the attribute">
    Select **Save**. The new attribute appears in the list and is available to sellers. Only a **Multi Select** attribute can be used as a variant axis.
  </Step>
</Steps>
